Speck is a family of lightweight block ciphers designed by the U.S. National Security Agency (NSA) in 2013 for resource-constrained devices such as microcontrollers. It is an Add-Rotate-XOR (ARX) cipher: each round uses only modular addition, bit rotation and XOR on two n-bit words, with no lookup tables, which keeps the code small and fast in software. For MAVLink protocol encryption, we use Speck 128/128 (128-bit block, 128-bit key, 32 rounds) in Counter (CTR) mode with a 128-bit IV, as in MAVShield (arXiv:2504.20626). CTR mode is selected because it produces ciphertext of the same size as the plaintext, maintaining MAVLink's strict message formatting. `speck.h` has the same API shape as `../AES/aes.h` (`SPECK_init_ctx_iv`, `SPECK_CTR_xcrypt_buffer`), so it can replace AES with a one-line change; it matches the paper's Speck128/128 test vector and the implementation deployed in the crypto_mavlink project byte for byte.
